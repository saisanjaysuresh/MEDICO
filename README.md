> **Notice**: Medico is an AI-assisted patient vitals monitoring and healthcare management platform designed for college project demonstrations and portfolio evaluation. All vital signs are generated by an in-memory Markovian simulation engine and are clearly labeled throughout the interface as **DEMO — SIMULATED VITALS**.

## 1. Executive Summary & Core Capabilities

Medico delivers a multi-screen, clinical-grade patient telemetry monitoring and decision-support web application built without frontend framework dependencies (pure HTML5, CSS3, and Vanilla JavaScript ES6+).

### Key Features
1. **Multi-Patient Telemetry Dashboard**: Live hospital census monitoring across 12 synthetic inpatient beds with color-coded severity indicators (Normal, Warning, Critical, Stale/Offline).
2. **Continuous Simulation Engine**: Realistic physiological drift using Markovian random walks around patient-specific baseline profiles (Heart Rate, $\text{SpO}_2$, Blood Pressure, Respiratory Rate, Temperature).
3. **Interactive Historical Waveforms**: High-resolution, multi-series time-series visualizations powered by Chart.js with dynamic time window filtering (15m, 1h, 6h, 24h).
4. **Deterministic Alert Rules Engine**: Evaluates observations against physiological thresholds, classifies severity (Critical, Warning, Informational), prevents alert duplication, and provides a formal clinical acknowledgment and resolution workflow.
5. **AI Clinical Decision Support**: Generates structured summaries (Observed Facts, Trend Interpretation, Limitations, Next Steps) and interactive natural-language clinical Q&A. Operates seamlessly with either external Google Gemini or a deterministic clinical rules fallback.
6. **Electronic Health Records & Patient Directory**: Full patient profiles with diagnoses, allergies, active medication orders, and doctor/nurse progress notes.
7. **Clinical Analytics & Reports**: Calculates descriptive statistics (Min, Max, Mean, Median, Count), browser CSV data exports, and print-ready clinical summaries.
8. **Role-Based Access Control**: Demonstrates role switching among Doctor (Lead Cardiologist), Nurse, Hospital IT Admin, and Family Caregiver.
9. **Simulation Presets & Scenarios**: Instant 1-click test scenarios for Tachycardia, Critical Hypoxemia, Sepsis Fever, Lead Disconnection, and Recovery.

### Prerequisites
- [Node.js](https://nodejs.org) (v18.0.0 or higher, tested on Node v24.14.0)
- Any modern web browser (Chrome, Edge, Firefox, Safari)

### Installation & Startup

1. **Clone or navigate to the project directory**:
   ```bash
   cd "c:/Users/sai sanjay/OneDrive/Desktop/medico"
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the application**:
   ```bash
   npm start
   ```
   *Or for development with automatic reload:*
   ```bash
   npm run dev
   ```

4. **Open your browser**:
   Navigate to: **[http://localhost:3000](http://localhost:3000)**

## 7. AI Decision Support & Deterministic Fallback

The backend exposes `/api/ai/insights` and `/api/ai/ask`.

### With Google Gemini API
To connect live Gemini AI:
1. Create a `.env` file from `.env.example`:
   ```bash
   cp .env.example .env
   ```
2. Set your API key:
   ```env
   GEMINI_API_KEY=your_google_gemini_api_key_here
   ```
3. Restart the server (`npm start`).

### Without API Key (Deterministic Fallback)
If `GEMINI_API_KEY` is blank or the external API is unreachable, Medico automatically engages its **Clinical Rules Engine Fallback**:
- Synthesizes factual observation data directly from telemetry buffers.
- Calculates trend vectors (rate of drift, cardiac/respiratory patterns).
- Explicitly flags data quality limitations.
- Recommends actionable nursing and physician verification protocols.
- **Safety Rule**: External AI failure never disables monitoring or deterministic threshold alert generation.

## 9. Security, Privacy & Clinical Compliance

1. **Zero Credential Exposure**: API keys, service credentials, and internal tokens are restricted strictly to backend Node.js environment variables.
2. **Synthetic Data Exclusivity**: All patient names, demographics, and clinical identifiers are entirely synthetic to prevent disclosure of real Protected Health Information (PHI).
3. **Role-Based Permission Enforcement**: Route and operational barriers ensure only authorized clinical roles perform sensitive operations (e.g., alert resolution, prescription notes).
4. **Clinical Disclaimer**: Medico provides decision support and telemetry visualization. It does not replace clinical judgment or provide autonomous diagnosis or prescription.
